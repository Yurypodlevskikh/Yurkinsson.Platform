Я бы предложил ещё один шаг

После того как всё снова соберётся, имеет смысл один раз полностью привести репозиторий к "профессиональному" виду:

единая структура каталогов;
единый .editorconfig;
Directory.Build.props;
Directory.Packages.props (централизованное управление версиями NuGet);
полноценный .gitignore;
GitHub Actions для сборки и тестов;
автоматический запуск тестов при каждом Push и Pull Request;
удобная настройка для Copilot Agent Mode.

Это делается один раз, а потом проект становится значительно проще поддерживать и развивать. Судя по тому, как ты планируешь строить несколько приложений вокруг общего сервиса аутентификации, такой фундамент окупится очень быстро.
